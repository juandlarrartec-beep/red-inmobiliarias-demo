# Red de inmobiliarias · demo navegable

Frontend de la plataforma, sin backend. Se abre `index.html` y se navega: ingreso, tres perfiles (inmobiliaria, administración e inversor), catálogo con filtros, tomar unidades con cuenta regresiva, registro de comprador, consultas, comisiones y accesos.

- Los datos son de ejemplo y se guardan solo en el navegador. «Reiniciar los datos de ejemplo» está en el menú del perfil.
- `capturas.html`: galería de las 13 pantallas del diseño original.
- `prototipo-escritorio.html`: el prototipo original de Claude Design.
- Sin build: HTML, CSS y JS planos. Se puede abrir con doble clic o servir desde cualquier hosting estático.
